接口列表

POST版面识别

上传图片进行版面识别和 OCR 文字识别

POST /layout
Content-Type: multipart/form-data

参数: file (图片文件)

返回:
{
  "id": "识别ID",
  "image": "图片文件名",
  "status": "success/error/partial",
  "results": [...]  // 版面识别结果（含 OCR 文本）
}

示例：

curl -X POST "http://localhost:8000/layout" -F "file=@document.png"

GET查看识别结果

根据 ID 获取完整的识别结果

GET /view/{id}

返回:
{
  "id": "识别ID",
  "created_at": "创建时间",
  "image_name": "图片名",
  "image_path": "图片路径",
  "status": "success/error/pending",
  "result_json": {...}  // 完整识别结果
}

GET获取图片

根据文件名获取原始图片

GET /image/{filename}

GET识别记录列表

获取最近的识别记录

GET /list

返回:
{
  "records": [
    {
      "id": "xxx",
      "created_at": "2024-01-01T12:00:00",
      "image_name": "document.png",
      "image_path": "xxx_document.png",
      "status": "success"
    },
    ...
  ]
}

GET可视化查看器

可视化查看识别结果，支持高亮区域和点击查看 OCR 文本

GET /viewer?id={识别ID}
