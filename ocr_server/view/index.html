OCR 识别
版面分析 + 全文字识别，自动检测标题、段落、表格、图片区域，按阅读顺序提取所有文字，支持中英混排。

Markdown 识别
将文档图片转为结构化 Markdown，保留标题层级、列表与段落，输出可直接粘贴编辑的纯文本，适合文档数字化。

结构化提取
输入图片 + 自定义 JSON 字段描述，模型按 Schema 提取指定字段并输出结构化 JSON，适合票据、表单等信息录入场景。
